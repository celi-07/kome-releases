# Kome for Windows

[Download the latest stable release](https://github.com/celi-07/kome-releases/releases/latest). Under **Assets**, choose the versioned `Kome-Setup-….exe` installer for Windows x64.

In an installed copy of Kome 3.35.2 or later, open Settings to check for updates, download an available version, and restart to apply it. If an older copy cannot contact its update service, run the latest installer once.

Each release includes its installer, blockmap and update manifests. The manifests identify the exact installer version, size and SHA-512 checksum.
